听到一个新方案时

按顺序记下：工作负载 → 原瓶颈 → 新抽象 → 关键权衡 → 量化结果 → 适用边界。

指标速查

指标 它回答什么 单独看会误判什么
TTFT 用户多久看到第一个 Token 看不到后续生成是否流畅
TPOT / ITL 后续 Token 间隔多大 看不到入口排队时间
Tokens/s 单请求或整机输出速度 不说明尾延迟和公平性
Cache Hit Rate 历史计算有多少被复用 高命中不保证传输成本低
GPU Utilization GPU 多长时间处于忙状态 忙碌可能来自低价值或低效率工作
MFU 实际有效计算相对理论峰值比例 对工作负载和统计口径敏感

六个高价值问题

  1. 旧方案在什么规模或流量特征下开始失效？
  2. 这个优化移动了瓶颈，还是消除了瓶颈？新瓶颈在哪里？
  3. 数字来自生产流量、压测还是模拟？基线是什么？
  4. 方案依赖哪种 GPU、网络和拓扑？换硬件后是否成立？
  5. 故障、扩缩容或滚动升级时，正在执行的请求会怎样？
  6. 哪部分已经开源并可复现，哪部分仍是内部系统？

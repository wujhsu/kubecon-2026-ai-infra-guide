三组必须分清的词

调度、编排、路由

  • 调度决定工作负载放在哪台机器、哪张设备上。
  • 编排管理它从创建、更新到销毁的完整生命周期。
  • 路由决定一次在线请求进入哪个可用副本。

延迟、吞吐、利用率

  • 延迟回答一个请求等多久。
  • 吞吐回答单位时间完成多少工作。
  • 利用率描述资源忙碌程度，但高利用率不一定等于高有效产出。

Checkpoint 与 KV Cache

Checkpoint 保存训练状态，用于失败后恢复；KV Cache 保存推理中的注意力历史，用于减少重复计算。二者都叫“缓存/保存”，生命周期和目标完全不同。
